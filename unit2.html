1.3 本章与 FRQ 的关联（备考重点提示）

本章覆盖的"判别-分支-循环-边界"四件套，是 Q1 与 Q2 的方法编写"地基"：

  • Q1 Methods and Control Structures：Part A 必含 if / while 嵌套，Part B 必调用 String 方法（与第一章强联动）。
  • Q2 Class Design：构造方法 + 实例变量初始化中大量使用 if-else 校验合法性。
  • Q3 ArrayList：仅考察 ArrayList 遍历与算法（属于第三章 Unit 4 范围），不属本章。
  • Q4 2D Array：仅考察 2D Array 遍历（属于第四章 Unit 4 范围），不属本章。
  • 本章明确不考 break / continue、StringBuilder、Array 等语法扩展——MCQ 与 FRQ 均严格落在 Topic 2.1–2.12 范围。

换句话说：本章是一切写代码题的内功。MCQ 也同样——Unit 2 的 Top 10 高频考点几乎全部是布尔表达式与循环计数的代码追踪。

1.4 本章学习目标（对应官方 12 个 Topic）

完成本章后应能：

  • 用比较运算符（==、!=、<、<=、>、>=）和逻辑运算符（&&、||、!）写出布尔表达式。
  • 理解短路求值（short-circuit evaluation）并能预测含副作用的复合条件的结果。
  • 运用 De Morgan 定律化简复杂布尔表达式。
  • 编写单分支、双分支、多分支（if / if-else / if-else if-else）以及嵌套 if。
  • 用 while 写计数器循环与哨兵循环，识别和避免无限循环。
  • 用 for 写定长迭代，掌握初始化、终止条件、步长三要素。
  • 用 String.length() + substring(i, i+1) 或 charAt(i) 遍历字符串每个字符。
  • 编写嵌套循环（外层 + 内层），明确总迭代次数 = 外层 × 内层。
  • 区分 =（赋值）与 ==（相等比较），理解 String 比较必须用 .equals() 的原因。
  • 在循环中正确使用复合赋值运算符 +=、-=、*=、/=、%= 以及自增/自减 ++/--。
  • 对 int 与 double 的混合运算、% 模运算、/ 整数除法保持警觉。
  • 能在 MCQ 中追踪 5–20 行代码段在控制流分支后的最终变量值；能识别 O(1) / O(n) / O(n²) 运行时间级别。

二、知识点与考点梳理（Topic 2.1–2.12）

本章共 12 个 Topic（依据 College Board《AP Computer Science A CED, Effective Fall 2025》），按知识结构分为六大板块。每个知识点均标注考纲 Learning Objective（LO）编号，便于对照官方大纲复习。

板块 S：算法与控制结构总览（Topic 2.1 / 2.9）

S1. Topic 2.1 — Algorithms with Selection and Repetition（LO 2.1.A–2.1.B）

核心概念：

  • 算法（Algorithm）：解决问题的有限步骤序列，APCSA 仅涉及选择（Selection）与重复（Repetition）两类控制结构。
  • 选择结构（Selection）：通过 if / if-else 让程序在不同输入下走不同分支。
  • 重复结构（Repetition）：通过 while / for 让同一段代码反复执行。
  • 本章所有算法本质上都是这两类结构的组合，先识别"分支点"再识别"循环点"。
// 例子：求 1+2+…+100 中所有算法骨架
int sum = 0;
for (int i = 1; i <= 100; i++) {     // Repetition
    sum += i;
}
if (sum > 5000) {                    // Selection
    System.out.println("big");
}

S2. Topic 2.9 — Implementing Selection and Iteration Algorithms（LO 2.9.A）

核心概念：

  • 把"伪代码/Pseudocode"翻译成可执行 Java 代码时要保留三件事：循环起止条件、每次迭代对变量的更新、终止边界。
  • 选择结构在 Java 中必须用 boolean 表达式作为条件，没有 0/1 自动转 boolean。
  • 实现策略："先写骨架（init → loop guard → body → update → return）" 再补语法细节。

A1. Topic 2.2 — Boolean Expressions：基本比较运算符（LO 2.2.A–2.2.B）

核心概念：

  • 基本类型 boolean：只能取 true 或 false 两个值（LO 1.2.B.1）。在 Java 中 1/0 不能直接当 boolean 用，这是与 C/Python 的关键差异。
  • 比较运算符（LO 2.1.A）——共六种，结果一律为 boolean：
运算符 含义 适用类型
== 等于 基本类型、boolean、引用类型（语义见下）
!= 不等于 同上
< 小于 int、double
<= 小于等于 int、double
> 大于 int、double
>= 大于等于 int、double
  • == 的引用陷阱（LO 2.1.B 高频考点！）：
  • 对基本类型，a == b 比较的是"值是否相等"；
  • 对引用类型（如 String、ArrayList），a == b 比较的是"是否同一个对象"，不是字符串内容相等！
  • 比较字符串内容必须用 a.equals(b)；比较时忽略大小写用 a.equalsIgnoreCase(b)。
  • 比较 ArrayList<String> 全部元素相等，需结合循环逐个调用 .equals()（详见第四章）。
String s1 = "hi";
String s2 = new String("hi");
System.out.println(s1 == s2);        // false（不同对象）
System.out.println(s1.equals(s2));   // true（内容相等）

int x = 5, y = 5;
System.out.println(x == y);          // true（值相等）

选择题考法：给一段 String 比较代码，问输出什么；或问"以下哪种比较字符串内容的方式正确"。

A2. Topic 2.5 — Compound Boolean Expressions：&& / || / !（LO 2.5.A）

核心概念：

  • &&（与）：左右都为 true 时整体为 true，否则为 false。
  • ||（或）：左右任一为 true 时整体为 true，都为 false 时才为 false。
  • !（非）：取反，单目运算符。
A B A && B A \|\| B !A
false false false false true
false true false true true
true false false true false
true true true true false

运算符优先级（必须背下来）：

  1. !（一元）— 最高
  2. 算术（*、/、%、+、-）
  3. 比较（<、<=、>、>=、==、!=）
  4. &&
  5. || — 最低

记忆口诀：非 → 算 → 比 → 与 → 或。即 ! 最先算，|| 最后算。

A3. Topic 2.6 — Comparing Boolean Expressions：De Morgan 与等价变换（LO 2.6.A）

De Morgan 定律（双等价式，常考题目"以下哪一项与之等价"）：

  • !(A && B) 等价于 !A || !B
  • !(A || B) 等价于 !A && !B

直观理解："整体否定 = 拆开否定后交换与或"。

// 原始：不是 (a > 0 且 b > 0)
boolean ok = !(a > 0 && b > 0);
// 等价：(用 De Morgan)
boolean ok2 = a <= 0 || b <= 0;

选择题考法：给一个布尔表达式，问"与之等价的是哪一项"。例如 !(x > 5 || y <= 0) 等价于 x <= 5 && y > 0。

A4. 短路求值（Short-circuit evaluation，Topic 2.5 拓展，LO 2.5.A）

核心规则：

  • A && B：若 A 为 false，则 B 不执行（结果必然 false）。
  • A || B：若 A 为 true，则 B 不执行（结果必然 true）。
int x = 0;
if (x != 0 && 10 / x > 1)  // x==0 时 && 后半段被跳过，不抛 ArithmeticException
{
    System.out.println("safe");
}

陷阱：考题经常设置"看起来会执行实际不会"的副作用语句，例如：

int a = 5, b = 10;
boolean result = (a > 10) && (b++ > 5);
System.out.println(b);   // 输出 10，b++ 没执行

选择题考法：追踪含 && / || 与副作用的代码段最终变量的值。

板块 B：if / Nested if 选择结构（Topic 2.3 / 2.4）

B1. Topic 2.3 — if Statements：if / if-else / if-else if-else（LO 2.3.A）

三种基本形态：

// 1. 单分支
if (条件) {
    // 只有条件为 true 才执行
}

// 2. 双分支
if (条件) {
    // 分支 A
} else {
    // 分支 B（条件为 false 时执行）
}

// 3. 多分支
if (条件 1) {
    // 1
} else if (条件 2) {
    // 2
} else if (条件 3) {
    // 3
} else {
    // 兜底
}

执行顺序：自顶向下判断，第一个满足的分支执行后立即跳出整条链，剩余分支不再检查。

B2. Topic 2.4 — Nested if Statements（LO 2.4.A）

在 if 块里再写 if。写法可读性较差，但题目经常出现，更推荐重构为"组合条件"或 else if 链。

if (age >= 13) {
    if (hasTicket) {
        System.out.println("可以进入");
    } else {
        System.out.println("需要票");
    }
} else {
    System.out.println("年龄不够");
}

选择题考法：给一段嵌套 if，问条件为何时执行某分支；或问输出结果。

板块 C：while 循环（Topic 2.7）

C1. Topic 2.7 — while Loops 语法与执行流程（LO 2.7.A）

int i = 0;             // 1. 初始化
while (i < 5) {        // 2. 条件判断
    System.out.println(i);
    i++;               // 3. 更新（必须有！否则死循环）
}

执行流程：先判条件 → 真则进入循环体 → 执行体一次 → 再回到条件判断 → 直到条件为假跳出。

典型陷阱：

  • 忘记更新 → 死循环（infinite loop），程序卡死。
  • 更新方向错误（如希望递增却写成 i--）→ 循环不执行或立即终止。
  • 条件永远为真（如 while (true) 且循环内不更新循环变量）→ 死循环。

C2. 哨兵循环（Sentinel loop，Topic 2.7 拓展，LO 2.7.B）

核心思想：用一个特殊值（如 -1、""、null）作为结束标志。

Scanner sc = new Scanner(System.in);
int sum = 0;
System.out.print("输入数字（0 结束）: ");
int n = sc.nextInt();
while (n != 0) {           // 0 是哨兵
    sum += n;
    System.out.print("输入数字（0 结束）: ");
    n = sc.nextInt();
}
System.out.println("sum = " + sum);

选择题考法：给一段 while 循环 + 输入序列，问最终 sum 多少 / 输出多少；或问"哨兵是哪个值"。

板块 D：for 循环与字符串算法（Topic 2.8 / 2.10 / 2.11）

D1. Topic 2.8 — for Loops 语法与三要素（LO 2.8.A）

for (初始化; 条件; 更新) {
    // 循环体
}

例：从 1 加到 100

int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}

三要素：

  1. 初始化：循环变量赋初值，仅执行 1 次。
  2. 条件：每次循环体执行前判断；为 false 则终止。
  3. 更新：每次循环体执行完后执行，再回到条件判断。

与 while 的关系：for 循环等价于 while，仅书写形式不同。for 适合"明确循环次数"的场景，while 适合"循环次数未知、依赖输入"的场景。

D2. Topic 2.10 — Implementing String Algorithms：字符串迭代（LO 2.10.A）

两种方式：

String s = "Hello";
// 方式一：length + charAt（最常用）
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
    System.out.println(c);
}
// 方式二：substring(i, i+1)（效率低但合法）
for (int i = 0; i < s.length(); i++) {
    String sub = s.substring(i, i + 1);
    System.out.println(sub);
}

考纲提示：for-each（增强 for）在 Unit 6 才正式登场，本章只用普通 for (int i = 0; ...)。

典型陷阱：s.length() 是方法调用，每次循环都重新计算。理论上可优化为 int n = s.length();，但选择题不考效率，所以直接 s.length() 即可。

D3. Topic 2.8 拓展 — 步长、反向与多变量（LO 2.8.B）

  • 步长可任意：例如 for (int i = 0; i < 10; i += 2) 输出 0,2,4,6,8。
  • 反向迭代：for (int i = s.length() - 1; i >= 0; i--)。
  • 多变量：for (int i = 0, j = 10; i < j; i++, j--)（少见但合法）。

D4. Topic 2.11 — Nested Iteration 嵌套循环（LO 2.11.A）

结构：

for (int i = 0; i < 3; i++) {         // 外层
    for (int j = 0; j < 4; j++) {     // 内层
        System.out.print("(" + i + "," + j + ") ");
    }
    System.out.println();
}
// 输出：
// (0,0) (0,1) (0,2) (0,3)
// (1,0) (1,1) (1,2) (1,3)
// (2,0) (2,1) (2,2) (2,3)

总迭代次数 = 外层 × 内层。例如 3×4 = 12 次。MCQ 常考这种"求循环总次数"题。

板块 R：Informal Run-Time Analysis（Topic 2.12）

R1. Topic 2.12 — Informal Run-Time Analysis：循环次数的 O() 估算（LO 2.12.A）

核心概念：

  • 常数级 O(1)：执行次数与输入规模无关，例如 if (x > 0)。
  • 线性 O(n)：执行次数与 n 成正比，例如 for (int i = 0; i < n; i++)。
  • 平方级 O(n²)：嵌套两层循环，例如 9×9 乘法表。
  • 指数 O(2ⁿ)：递归求斐波那契（本章不深考）。
// O(1)
if (num > 0) { ... }

// O(n)
for (int i = 0; i < n; i++) {
    System.out.println(i);
}

// O(n²)
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.print("*");
    }
    System.out.println();
}

选择题考法：给定一段嵌套循环，问"输入 n 时总执行次数是多少"（答案通常是 n² 级别，常数 n，n(n+1)/2，n²-n 等）。MCQ 不考 O() 严格定义，只识别"线性"与"平方级"差异即可。

板块 F：易错点专题（综合）

F1. = vs ==（LO 2.1.A 巩固）

int a = 5;
if (a = 10) { /* 编译错误 */ }   // 编译期报错：int 不能转 boolean
boolean b = false;
if (b = true) { /* 合法！b 被赋值为 true，进入分支 */ }

在 if (...) 中写成 b = true 是合法代码，但语义是把 true 赋给 b，永远进入 if 体——是高频 bug 源。

F2. 自增自减与复合赋值（LO 2.11.A）

  • i++ / i--：先用再加 / 减。
  • ++i / --i：先加 / 减再用。
  • i += 2 等价于 i = i + 2；*=、/=、%= 类似。

选择题考法：追踪 int x = 5; int y = x++; 与 int y = ++x; 后 x、y 的值。

F3. 整数除法与模运算（LO 2.12.A）

  • 整数除法 /：7 / 2 == 3（截断小数部分，不四舍五入）。
  • 模 %：7 % 2 == 1（余数，符号与被除数一致）。
  • 混合运算优先级：int / int → int，运算前就会截断；想保留小数需先转 double：7.0 / 2 == 3.5。

典型陷阱：

int a = 7, b = 2;
System.out.println(a / b);          // 3（整数除）
System.out.println((double) a / b); // 3.5
System.out.println(a % b);          // 1

F4. 隐式类型提升（LO 2.13.A）

  • int 与 double 运算时，int 自动提升为 double。
  • 但 int / int 仍是 int（提升发生在赋值前）。
int x = 5;
double y = x / 2;     // y = 2.0（先 int 除得 2，再转 double）
double z = x / 2.0;   // z = 2.5（int 转 double 后再除）

三、本章重难点与易错点清单（按出错频率排序）

这份清单基于近五年（2021–2025）AP Classroom Unit 2 选择题错题分布。

高频易错点 TOP 10

  1. String 用 == 比较内容 — 编译通过、运行"看起来对"，但内容不同时仍返回 false。必记口诀：内容比较必 .equals()。
  2. = 误写成 == — 在 if (x == 5) 中漏写一个等号变成 if (x = 5)，int 变量会编译错误；boolean 变量则语义改变。
  3. while 死循环 — 忘记在循环体中更新循环变量。
  4. for 终止条件差一 — i <= n vs i < n，多一个少一个就是 bug。
  5. 嵌套循环总次数混淆 — 把内层循环次数当作总次数，忘记乘以外层。
  6. 模运算理解成"找倍数" — 7 % 2 == 1 经常被误答成 5 或 3。
  7. 整数除截断 — 7 / 2 期望得 3.5，实际是 3。
  8. De Morgan 定律化简错 — !(A || B) 错写成 !A || !B，正确应为 !A && !B。
  9. 独立 if 链 vs else if 链混淆 — 误以为多个独立 if 等价于 else if 链，实际结果会被后面的 if 覆盖。
  10. 短路求值的副作用忽略 — if (false && (i++ > 0)) 中 i++ 不执行，输出仍是原值。

学习建议

  • 先做 5 道 if-else MCQ，再学 while。选择结构是循环结构的基础。
  • 手写 10 遍 for 循环三要素：分别写"遍历字符串"、"求 1..n 和"、"嵌套循环输出 9×9 乘法表"。
  • 把每一道错题"翻译"成一句话：例如 "我把 s == t 当成内容比较了"→ 加深 == 引用陷阱印象。
  • 写题先模拟：拿到一段代码段，先用人手走一遍每行执行，再与答案对比。

MCQ-1（&&/|| 短路、De Morgan）

英文原题：

Consider the following code segment.

boolean b1 = true && ((5 % 2) == 0);
boolean b2 = /* missing expression */;

1. Which of the following can replace /* missing expression */ so that the value stored in b2
   is the same as the value stored in b1 after the code segment has executed?

(A) false || ((5 % 2) == 1)
(B) false && ((5 % 2) == 1)
(C) true  || ((5 % 2) == 1)
(D) true  && ((5 % 2) == 1)

中文解读：5 % 2 == 0 是 false，所以 b1 = true && false = false。要找 b2 = false 的表达式。利用短路求值，false || ... 是 false（不论右边）；false && ... 是 false；true || ... 是 true；true && ... 是 (5%2==1) = true。只有 (A) 必为 false。

答案：A

解析：考察 && / || 短路求值。false || X 永远是 false，无需关心 X 的值；true && X 的值取决于 X。(B) 中 false && true == false 也是 false，但是若 X 不是 (5%2)==1 时结果仍为 false，不唯一确定。题目要求"b2 与 b1 始终相同"，必须保证无论 X 怎么变，b2 都是 false——只有 (A) false || X 满足。

MCQ-2（混合条件运算符优先级）

英文原题：

Consider the following code segment.

if (false && true || false)
{
    if (false || true && false)
    {
        System.out.print("First");
    }
    else
    {
        System.out.print("Second");
    }
}
if (true || true && false)
{
    System.out.print("Third");
}

2. What is printed as a result of executing the code segment?

(A) Second
(B) Third
(C) FirstThird
(D) SecondThird

中文解读：先算 &&，后算 ||：

  • 外层 if (false && true || false)：先算 false && true == false，再 false || false == false。整个外层 if 跳过，内部两个 print 都不执行。
  • 第二个 if (true || true && false)：先 true && false == false，再 true || false == true。进入 if，打印 Third。

答案：B

解析：优先级 ! > 算 > 比 > && > ||。题目的迷惑点在于把 || 写在 && 前，但运算仍按优先级进行。

MCQ-3（for 循环 + 字符串反向遍历）

英文原题：

Consider the following method.

public static String changeStr(String str)
{
    String result = "";
    for (int i = str.length() - 1; i >= str.length() / 2; i -= 2)
    {
        result += str.substring(i, i + 1);
    }
    return result;
}

3. What value is returned as a result of the method call changeStr("12345")?

(A) "4"
(B) "53"
(C) "531"
(D) "543"

中文解读：str.length() = 5。

  • 初始化 i = 4：取 str.substring(4, 5) = "5"，result = "5"，i = 4 - 2 = 2。
  • i = 2 >= 5/2 = 2：取 str.substring(2, 3) = "3"，result = "53"，i = 2 - 2 = 0。
  • i = 0 >= 2：false，退出循环。

最终返回 "53"。

答案：B

解析：关键在于 >= 边界与 i -= 2 的步长。手算三步循环即可：i 依次为 4、2、0；只有 4 和 2 满足 i >= str.length()/2，所以 result 拼接两个字符。

MCQ-4（独立 if 链 vs if-else if 链行为差异）

英文原题：

Consider the following code segments, which are each intended to convert grades
from a 100-point scale to a 4.0-point scale and print the result. A grade of 90 or
above should yield a 4.0, a grade of 80 to 89 should yield a 3.0, a grade of 70 to
79 should yield a 2.0, and any grade lower than 70 should yield a 0.0.

Assume that grade is an int variable that has been properly declared and initialized.

Code Segment 1
double points = 0.0;
if (grade > 89)
{
    points = 4.0;
}
else if (grade > 79)
{
    points = 3.0;
}
else if (grade > 69)
{
    points = 2.0;
}
else
{
    points = 0.0;
}
System.out.println(points);

Code Segment 2
double points = 0.0;
if (grade > 89)
{
    points = 4.0;
}
if (grade > 79)
{
    points = 3.0;
}
if (grade > 69)
{
    points = 2.0;
}
if (grade < 70)
{
    points = 0.0;
}
System.out.println(points);

7. Which of the following statements correctly compares the values printed by the two code segments?

(A) The two code segments print the same value only when grade is below 80.
(B) The two code segments print the same value only when grade is 90 or above.
(C) Both code segments print the same value for all possible values of grade.
(D) The two code segments print different values for all possible values of grade.

中文解读：分段 1 是标准 else if 链；分段 2 是 4 个独立 if，全部判断、全部执行。

  • grade = 95：
  • 段 1：points = 4.0，然后不再进入 else if。打印 4.0。
  • 段 2：第一个 if (95>89) 设 points = 4.0；第二个 if (95>79) 设 points = 3.0；第三个设 points = 2.0；第四个 95<70 假。打印 2.0！

  • 不一致。

  • grade = 50：

  • 段 1：else 分支设 points = 0.0。打印 0.0。
  • 段 2：前 3 个 if 都不满足；第四个 50<70 真，设 points = 0.0。打印 0.0。
  • 一致。

所以两种结构在 grade<70 时结果一致，其他情况下不一致。

答案：A

解析：考察独立 if 与 if-else 链的行为差异。最容易出错的是"独立 if 一定会输出最大的匹配条件"——错的，因为最后会被后面的 if 覆盖。

MCQ-5（De Morgan / 表达式真值表）

英文原题：

In the following Boolean expressions, x and y are properly declared and initialized
boolean variables.

Expression A
x && y

Expression B
!x && !y

8. Which of the following best describes the relationship between values produced by
   Expression A and Expression B?

(A) Expression A and Expression B evaluate to different values for all values of x and y.
(B) Expression A and Expression B evaluate to the same value for all values of x and y.
(C) Expression A and Expression B evaluate to the same value only when x and y have the same value.
(D) Expression A and Expression B evaluate to the same value only when x and y have different values.

中文解读：列出真值表：

x y A: x && y B: !x && !y
false false false true
false true false false
true false false false
true true true false
  • 当 x、y 相同时：(F,F) 时 A=F, B=T 不一致；(T,T) 时 A=T, B=F 不一致。所以"x、y 相同"时反而不同。
  • 当 x、y 不同时：两种组合都是 A=F, B=F，相等。

答案：D

解析：考察真值表与 De Morgan 定律（!x && !y ≡ !(x || y)）。本表达式与 x && y 互为否定但不总是反义——只在 (x, y) 一致时一致。

MCQ-6（while 循环输出追踪）

英文原题：

Consider the following code segment.

int num = 1;
int count = 0;
while (num <= 5)
{
    if (num % 2 == 0)
    {
        count++;
    }
    num++;
}
System.out.println(count);

10. What is printed as a result of executing the code segment?

(A) 2
(B) 3
(C) 5
(D) 7

中文解读：while 循环 num 从 1 到 5，统计偶数出现次数：

  • num=1：奇数，count 不变；num++ → 2
  • num=2：偶数，count=1；num++ → 3
  • num=3：奇数；num++ → 4
  • num=4：偶数，count=2；num++ → 5
  • num=5：奇数；num++ → 6
  • num=6>5：退出

最终 count = 2。

答案：A

解析：典型 while + 计数 MCQ。务必手算每一轮 num 与 count 的值，不要跳步。

MCQ-7（整数除法 + 双重嵌套循环计数）

英文原题：

Consider the following code segment.

int count = 0;
for (int i = 0; i < 4; i++)
{
    for (int j = i; j < 4; j++)
    {
        count++;
    }
}
System.out.println(count);

13. What is printed as a result of executing the code segment?

(A) 4
(B) 8
(C) 10
(D) 16

中文解读：外层 i = 0,1,2,3；内层 j 从 i 到 3（不含 4）：

  • i=0：j = 0,1,2,3，共 4 次
  • i=1：j = 1,2,3，共 3 次
  • i=2：j = 2,3，共 2 次
  • i=3：j = 3，共 1 次

总和 = 4 + 3 + 2 + 1 = 10。

答案：C

解析：内层起始条件随外层变化时，总次数不再是简单 m × n。这类题常考"递减次数"——列清单是最稳的方式。

MCQ-8（String 比较 + 判别陷阱）

英文原题：

Consider the following code segment.

String a = new String("cat");
String b = new String("cat");
String c = a;
boolean p = (a == b);
boolean q = (a.equals(b));
boolean r = (a == c);

14. What are the values of p, q, and r after the code segment has executed?

(A) p is true,  q is true,  r is true
(B) p is false, q is true,  r is true
(C) p is false, q is true,  r is false
(D) p is true,  q is false, r is false

中文解读：

  • a 与 b 是用 new String(...) 创建的两个不同对象，内容相同但不是同一对象。
  • c = a 是引用赋值，c 与 a 指向同一个对象。
  • a == b：比较引用，false。
  • a.equals(b)：比较内容，true。
  • a == c：同一对象，true。

答案：B

解析：考察 == 与 .equals() 在 String 上的差异，以及引用赋值的语义。这是 Unit 1 + Unit 2 联合考点，全文最高频出错题之一。

MCQ 限时训练建议：以上 10 题计时 25 分钟完成，平均 2.5 分钟/题。新版考纲的 MCQ 1–4 选项很少出现"明显送分"，必须手算才能拿稳分。

FRQ-1（AP Classroom Unit 2 FRQ Part A · BeadSequence）

Part A · Official English Wording (from College Board Unit 2 Progress Check FRQ Part A)

This question involves processing a String that represents a sequence of beads.

The String variable beadSequence represents a bead sequence. It contains a
sequence of letters in which each letter represents the color of a bead.

A bead sequence is considered acceptable if it adheres to the following rules.
Otherwise, it is not considered acceptable.

- Rule 1: The number of beads in the sequence is between 5 and 10, inclusive.
- Rule 2: The sequence contains at least one blue bead (represented by "B") and
          at least one white bead (represented by "W").
- Rule 3: The sequence starts and ends with the same color.

You will create three boolean variables to help determine whether the sequence
is acceptable, and then print a message indicating the result. The following
table illustrates the intended behavior for different values of beadSequence.

Value of beadSequence    Meets Rule 1   Meets Rule 2   Meets Rule 3   Printed Output
"OBWO"                   false          true           true          "Not acceptable"
"BWBGOGWBB"              true           true           true          "Acceptable"
"ROYGBIVW"               true           true           false         "Not acceptable"
"BOBOBOBO"               true           false          false         "Not acceptable"
"WBWRWBWRWBWR"           false          true           false         "Not acceptable"
"BWWWBBWWWB"             true           true           true          "Acceptable"

1. Write a code segment that creates a boolean variable named lengthGood and
   assigns it true if beadSequence meets rule 1 and assigns it false otherwise.

2. Write a code segment that creates a boolean variable named correctColors and
   assigns it true if beadSequence meets rule 2 and assigns it false otherwise.

3. Write a code segment that creates a boolean variable named startEndGood and
   assigns it true if beadSequence meets rule 3 and assigns it false otherwise.

4. Write a code segment that prints "Acceptable" if beadSequence adheres to all
   three rules and prints "Not acceptable" otherwise. You must use the variables
   lengthGood, correctColors, and startEndGood to receive full credit, regardless
   of what you wrote for parts A, B, and C.

中文思路

Part A 一道题含 4 个子问题，考点全部是 Unit 2 标准选择结构：

  • (1) 长度条件：5 ≤ length ≤ 10。
  • (2) 至少一个 'B' 和至少一个 'W'：必须分别检查两个字符，或用循环扫描。
  • (3) 首尾字符相同：.charAt(0) 与 .charAt(length - 1) 比较，注意非空字符串的前提。
  • (4) 三个 boolean 与运算后输出。

参考解法

// (1) 长 5..10
boolean lengthGood = beadSequence.length() >= 5 && beadSequence.length() <= 10;

// (2) 至少一个 B 和一个 W
boolean hasB = false, hasW = false;
for (int i = 0; i < beadSequence.length(); i++) {
    char c = beadSequence.charAt(i);
    if (c == 'B') hasB = true;
    if (c == 'W') hasW = true;
}
boolean correctColors = hasB && hasW;

// (3) 首尾同色（要求 beadSequence 非空）
boolean startEndGood = beadSequence.length() > 0
        && beadSequence.charAt(0) == beadSequence.charAt(beadSequence.length() - 1);

// (4) 合并
if (lengthGood && correctColors && startEndGood) {
    System.out.println("Acceptable");
} else {
    System.out.println("Not acceptable");
}

评分要点

  • (1) 1 分：正确写出 5..10 闭区间表达式。
  • (2) 1 分：用 .indexOf("B") >= 0 或循环都能得分。
  • (3) 1 分：未处理空字符串可能要扣 0.5。
  • (4) 1 分：必须使用前三个变量——若新写一遍条件直接判三规则，此项不得分。

FRQ-2（AP Classroom Unit 2 FRQ Part B · colWidth 字符串填充）

Part A · Official English Wording (from College Board Unit 2 Progress Check FRQ Part B, Question 1)

This question involves processing strings of text.

Consider the following variables.
- colWidth is an int variable with a positive value.
- text is a String variable with a non-null value.
- otherText is a String variable with a non-null value.

1. A code segment, which you will write, should print output according to the
   following rules.

- If the length of text is greater than colWidth, then the value of text will
  be printed.
- Otherwise, the printed output will consist of colWidth characters contained
  between two "|" characters. The text between the "|" characters will consist
  of a sequence of periods ("."), followed by the value of text, followed by
  another sequence of periods.
- The printed output will have an equal number of periods on each side of
  text, if possible. If this is not possible, then there will be one fewer
  period on the left side of text than on the right side of text.

Value of colWidth   Value of text   Printed Output
5                   "ab"            |.ab..|
5                   "abc"           |.abc.|
10                  "ab"            |....ab....|
10                  "abc"           |...abc....|
10                  "abcdefghij"    |abcdefghij|
10                  "abcdefghijk..."  abcdefghijk...   (no bars, length > colWidth)

Write a code segment to print the intended output. Your implementation must
meet all specifications and conform to the examples shown in the table.

中文思路

分两种情形：length > colWidth 直接打印；否则用点填充到 colWidth 字符。

点的总数量 = colWidth - text.length()，左右分布：左侧 left = total/2，右侧 right = total - left。

参考解法

if (text.length() > colWidth) {
    System.out.println(text);
} else {
    int totalDots = colWidth - text.length();
    int leftDots  = totalDots / 2;            // 整数除，向下截断
    int rightDots = totalDots - leftDots;     // 多出来的点放右侧
    // 打印
    System.out.print("|");
    for (int i = 0; i < leftDots; i++)  System.out.print(".");
    System.out.print(text);
    for (int i = 0; i < rightDots; i++) System.out.print(".");
    System.out.println("|");
}

评分要点

  • 正确判断 "length > colWidth" 走分支，1 分。
  • 用整数除法分点：totalDots/2 给左、剩余给右，1 分。
  • 用循环或 String.repeat 都能得分（考纲允许 String.repeat）。
  • 使用 | 包裹内容 1 分。

FRQ-3（AP Classroom Unit 2 FRQ Part B · 最长公共前缀）

Part A · Official English Wording (from College Board Unit 2 Progress Check FRQ Part B, Question 2)

2. A code segment, which you will write, should print the length of the longest
   prefix of the text that is a substring of otherText. A prefix is a substring
   that occurs at the beginning of another string.

Value of text     Value of otherText   Printed Output   Explanation
"apple"           "pear"               1                The prefix "a" is a substring of "pear", but "ap" is not.
"apple"           "pineapple"          5                The prefixes "a", "ap", "app", "appl", and "apple" are
                                                      substrings of "pineapple". The length of the longest
                                                      substring is 5.
"apple"           "happy"              3                The prefixes "a", "ap", and "app" are substrings of
                                                      "happy". The length of the longest substring is 3.
"apple"           "leek"               0                No prefix of "apple" is a substring of "leek".

Write a code segment to print the intended output. Your implementation must
meet all specifications and conform to the examples shown in the table.

中文思路

从长到短依次检查 text.substring(0, k) 是否在 otherText 中，一旦命中立即输出 k。关键技巧：用 otherText.indexOf(prefix) >= 0 检查子串。

参考解法

int answer = 0;
boolean found = false;
for (int k = text.length(); k >= 1 && !found; k--) {
    String prefix = text.substring(0, k);
    if (otherText.indexOf(prefix) >= 0) {
        answer = k;
        found = true;                       // 第一个命中即最长
    }
}
System.out.println(answer);

评分要点

  • 用 indexOf 检查子串 1 分。
  • 从长到短遍历前缀，找到即设置 found（或等价布尔变量）提前结束 1 分。
  • 若用从短到长、需要每命中更新 answer，可以等价得分，但代码略长。

FRQ-4（AP Classroom Unit 2 FRQ Part B · 个位数恰好出现 1 次）

Part A · Official English Wording (from College Board Unit 2 Progress Check FRQ Part B, Question 3)

This question involves writing two code segments that use information about
downloaded songs.

A record company uses the following variables to maintain information about each
song in the company's catalog.
- downloads is an int variable that represents the number of times a song was
  downloaded. Assume the value of this variable is positive.
- songInfo is a String variable that contains information about the song. The
  string consists of the artist name, followed by a hyphen ("-"), followed by
  the album title, followed by another hyphen, followed by the song title.
  Assume that no other hyphens appear in the string.

3. A code segment, which you will write, should determine whether the ones
   digit of the number stored in downloads appears exactly one other time in
   the number. If so, the code segment should print "exactly once";
   otherwise, it should print "not exactly once".

   For example, if downloads has a value of 1734567, then the segment should
   print "exactly once" because the ones digit, which is 7, appears one
   other time.

   As another example, if downloads has a value of 325322, then the segment
   should print "not exactly once" because the ones digit, which is 2,
   appears two other times.

Write a code segment to print the intended output. Your implementation must
conform to the examples.

中文思路

先取个位数 int ones = downloads % 10;，再统计去掉个位后其余位中等于 ones 的个数。

  • 计数 = 1 → "exactly once"
  • 否则 → "not exactly once"

参考解法

int ones = downloads % 10;
int otherCount = 0;
int n = downloads / 10;             // 去掉个位
while (n > 0) {
    if (n % 10 == ones) otherCount++;
    n /= 10;
}
if (otherCount == 1) {
    System.out.println("exactly once");
} else {
    System.out.println("not exactly once");
}

评分要点

  • 用 % 10 取个位 1 分。
  • 用 / 10 循环剥离剩余位 1 分。
  • 准确比对计数 == 1 输出 1 分。

FRQ-5（AP Classroom Unit 2 FRQ Part B · songInfo 提取）

Part A · Official English Wording (from College Board Unit 2 Progress Check FRQ Part B, Question 4)

4. A code segment, which you will write, should process the string songInfo
   and print the song title and artist name separated by the string (" by ").

   For example, if songInfo is "Carrie Ferriero-Greatest Hits-Tell Me Why",
   then the code segment should print "Tell Me Why by Carrie Ferriero".

   As another example, if songInfo is "Aniita-Mixtape 2-How Much More", then
   the code segment should print "How Much More by Aniita".

Write a code segment to print the intended output. Your implementation must
conform to the examples.

中文思路

字符串形如 "artist-album-title"，有两个连字符。要切三段：

  1. 第一个 - 之前是 artist；
  2. 最后一个 - 之后是 title；
  3. 中间是 album（不需要输出）。

注意：artist 与 album 都可能含空格（如 "Aniita"、"Mixtape 2"），而题目保证不含其他连字符。

参考解法

int firstDash = songInfo.indexOf('-');
int lastDash  = songInfo.lastIndexOf('-');

String artist = songInfo.substring(0, firstDash);
String title  = songInfo.substring(lastDash + 1);  // 含 lastDash+1 到末尾

System.out.println(title + " by " + artist);

评分要点

  • 用 indexOf 与 lastIndexOf 准确切分 1 分。
  • 拼成 "title by artist" 顺序正确 1 分。
  • 不必提取 album（题目不要），但若写出可酌情。
