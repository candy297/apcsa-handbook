使用说明

给老师的一份简明操作手册。

一、三大入口

根据你现在的需求选择入口。

  • 按年份看真题 —— 首页点击「2026 年真题」等卡片，得到该年度全部题目，适合期末整卷复习。
  • 按知识点组题 —— 首页点击 Unit 卡片（或左侧栏展开 Unit），得到该章所有题目，适合单元测、专题补漏。
  • 全文搜索 —— 在题库页搜索框输入 substring、ArrayList、recursion 等关键词， 把散落在不同 Unit、不同年份的同类题一次找齐。

二、筛选与组题

  • 左侧栏为多选筛选：题型（MCQ / FRQ）、年份、大纲知识点（Unit → Topic 两级）、来源（哪一套卷）。多个条件之间是「且」的关系。
  • 筛选项下方括号内的数字是该条件下有多少题，方便判断覆盖度。
  • 点「全选当前结果」可把当前筛选出的题目一次性加入题车（例如「Unit 4 全部 144 题」）。
  • 题车保存在浏览器本地，关闭页面、第二天打开仍然在。右下角浮条实时显示已选数量。

三、导出试卷

  • 导出 Word (.docx) —— 生成真正的 Word 文件，可继续编辑（改字号、加校徽、插入答题栏）。卷头含标题、副标题、题量、班级姓名学号栏。
  • 打印 / 导出 PDF —— 用浏览器打印对话框「另存为 PDF」，排版更紧凑，适合直接发电子版。
  • 复制为 Markdown —— 粘贴到在线文档、Notion 或钉钉/企业微信里快速分享。
  • 内容选项可控制是否附带答案、是否附带解析。做成学生卷时把两者关掉，再设置「每道题后留空 N 行」即可。
  • FRQ 的「解析」输出的是 College Board 官方 Scoring Guidelines（评分标准），可直接用于讲评与自评。

四、考点标注的可信度

  • 官方标注 —— 该题的 Unit / Topic / Learning Objective 直接取自官方 Skill & Learning Objective 对齐表， 标注完全准确（目前为官方模考 Practice 1 的 40 道题）。
  • 其余题目由关键词自动归类到 CED Topic。题干的语法特征大部分时候足够明确（如出现 substring 即归入 1.15）， 但少数跨知识点的题可能归错。建议组卷前快速扫一眼题目标签。
  • Unit 层级（Unit 1–4）对 AP Classroom 题库是完全准确的（按官方章节组织）；年份与来源标注均准确。

五、2025 版 CED 结构对照

2025 年秋季起，AP CSA 把原有 10 个 Unit 合并为 4 个 Unit，考试仍为 MCQ 42 题 / 90 分钟 + FRQ 4 题 / 90 分钟，全程 Bluebook 机考。

旧大纲的 Unit 1–10 与本版的对应关系：U1 Primitive Types / U2 Using Objects → Unit 1； U3 Boolean / U4 Iteration → Unit 2；U5 Writing Classes → Unit 3； U6 Array / U7 ArrayList / U8 2D Array / U9 Inheritance / U10 Recursion → Unit 4。因此 2022–2024 年的真题也能按新大纲查找。

六、数据来源与版权

题目与解析来自 College Board 官方资料（AP Classroom Progress Check / Topic Questions、官方模考试卷、历年 Free-Response Questions 与 Scoring Guidelines）， 整理自本机工作区教学资料。版权归 College Board 所有，仅限课堂教学使用，请勿公开传播或用于商业用途。

题目文字由 PDF 自动提取后逐题校对，如发现个别题干换行、代码缩进或选项错位，请在题库维护页反馈题目编号。
