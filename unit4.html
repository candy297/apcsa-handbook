二、知识点与考点梳理（Topic 4.1–4.17）

板块 A：数据基础与伦理（Topic 4.1 / 4.2）

Topic 4.1 数据收集的伦理与社会影响

考点：MCQ 高频考「隐私保护」「算法偏见」「数据质量」三个概念。

概念 考试表述
隐私（Privacy） 当用户在 App、网站中输入个人信息（姓名 / 位置 / 购物记录）时，这些数据可能被收集、存储、甚至售卖；程序员应尝试保护用户隐私。
算法偏见（Algorithmic Bias） 系统性、重复性的程序错误，导致对特定用户群体不公平的结果。例如训练数据中只包含某一族群的照片，人脸识别对其他族群准确率显著降低。
数据质量（Data Quality） 数据集可能不完整（缺失值）、不准确（错误值）、有偏差（采样不均）；使用前应评估数据质量。

典型 MCQ 题干：「A programmer is designing an app that recommends restaurants to users based on past dining history. Which of the following is the most important ethical consideration?」

板块 B：1D Array 三件套（Topic 4.3 / 4.4 / 4.5）

Topic 4.3 一维数组的创建与访问

两种初始化语法（考试重点）：

// 语法 A：先 new，再赋值
int[] nums = new int[5];
nums[0] = 10; nums[1] = 20; nums[2] = 30; nums[3] = 40; nums[4] = 50;

// 语法 B：初始化列表（仅声明时可用）
int[] nums = {10, 20, 30, 40, 50};
String[] names = {"Alice", "Bob", "Carol"};
double[] prices = new double[]{9.99, 19.99, 29.99}; // new double[] 也可以省略

核心规则：
- 数组下标从 0 开始，到 length - 1 结束；
- 数组长度不可变（一旦 new 出，大小就锁死；试图 nums.length++ 会编译报错）；
- 访问越界下标会抛 ArrayIndexOutOfBoundsException（运行期错误，编译不会报错）。

数组作为方法参数 / 返回值：

public static int sum(int[] arr) {  // 接收数组引用
    int total = 0;
    for (int x : arr) {
        total += x;
    }
    return total;
}
public static int[] reverse(int[] arr) {  // 返回新数组
    int[] result = new int[arr.length];
    for (int i = 0; i < arr.length; i++) {
        result[i] = arr[arr.length - 1 - i];
    }
    return result;
}

Topic 4.4 数组遍历

两种遍历语法（考试必会）：

int[] nums = {10, 20, 30, 40, 50};

// 语法 A：传统 for（需要下标时用）
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

// 语法 B：增强 for（只读访问时用，更简洁）
for (int n : nums) {
    System.out.println(n);
}

遍历模式变种（MCQ 高频）：
- 正向遍历：for (int i = 0; i < nums.length; i++)
- 反向遍历：for (int i = nums.length - 1; i >= 0; i--)
- 每隔一个：for (int i = 0; i < nums.length; i += 2)
- 跳过首尾：for (int i = 1; i < nums.length - 1; i++)

遍历中的修改陷阱：增强 for 不能用于修改数组元素（修改的是循环变量，不影响原数组）；若要修改必须用传统 for + 下标。

int[] nums = {1, 2, 3};
for (int n : nums) {
    n = n * 2;  // ❌ 无效，n 是循环副本
}
for (int i = 0; i < nums.length; i++) {
    nums[i] *= 2;  // ✅ 正确
}

Topic 4.5 数组算法实现

五大基础算法（FRQ 高频）：

// 1. 求和 / 平均
public static int sum(int[] arr) {
    int total = 0;
    for (int x : arr) {
        total += x;
    }
    return total;
}
public static double average(int[] arr) {
    return (double) sum(arr) / arr.length;
}

// 2. 最大 / 最小
public static int max(int[] arr) {
    int best = arr[0];
    for (int i = 1; i < arr.length; i++) {
        if (arr[i] > best) best = arr[i];
    }
    return best;
}

// 3. 计数（满足条件的元素个数）
public static int countAbove(int[] arr, int threshold) {
    int count = 0;
    for (int x : arr) {
        if (x > threshold) count++;
    }
    return count;
}

// 4. 查找（返回下标或 -1）
public static int find(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

// 5. 复制（部分 / 全部）
public static int[] copy(int[] arr) {
    int[] result = new int[arr.length];
    for (int i = 0; i < arr.length; i++) {
        result[i] = arr[i];
    }
    return result;
}

考试常见变种：
- 「统计数组中相邻两个相等的对数」：for (int i = 0; i < arr.length - 1; i++) { if (arr[i] == arr[i+1]) count++; }
- 「数组是否已排序（升序）」：检测每一对 arr[i] > arr[i+1]；
- 「找第二大的元素」：先找 max，再遍历找 < max 的最大。

板块 C：文本文件 + 包装类（Topic 4.6 / 4.7）

Topic 4.6 文本文件读入

考试必备模板（MCQ 必会、FRQ 不直接考但工程中常用）：

import java.util.Scanner;
import java.io.File;
import java.io.FileNotFoundException;

public static void readFile(String filename) throws FileNotFoundException {
    Scanner sc = new Scanner(new File(filename));
    while (sc.hasNext()) {
        int n = sc.nextInt();
        System.out.println(n);
    }
    sc.close();
}

// 简单用法：通常 AP 题目把异常处理隐藏，直接给一个已打开的 Scanner
public static double average(Scanner sc) {
    double sum = 0;
    int count = 0;
    while (sc.hasNext()) {
        sum += sc.nextDouble();
        count++;
    }
    return count == 0 ? 0 : sum / count;
}

关键区分（MCQ 高频陷阱）：

方法 用途 注意
hasNext() 还有没有下一个 token（任意类型） 用于 while 循环条件
next() 读取下一个 token（按空白切分） 自动跳过分隔符
nextInt() 读取下一个 int 同上
nextLine() 读取整行（直到换行） 会读走上一行的换行符，紧跟 nextInt() 后会读到空行

考试常见陷阱：

// ❌ 错误用法：nextInt 后立刻 nextLine
Scanner sc = new Scanner("42\nhello world");
int n = sc.nextInt();      // 读 42，留下 \n
String line = sc.nextLine(); // ❌ 读到的是 ""（空字符串），因为只读到了 \n

// ✅ 正确：在 nextInt 后多读一行换行符
sc.nextLine();  // 吃掉 \n
line = sc.nextLine();  // 读到 "hello world"

Topic 4.7 包装类（Wrapper Classes）

核心概念：基本类型没有方法，要调用方法必须包装为对象。APCSA 只要求掌握 Integer 与 Double 两个包装类。

基本类型 包装类 考查的方法 / 常量
int Integer Integer.parseInt(String) / Integer.MAX_VALUE / Integer.MIN_VALUE
double Double Double.parseDouble(String) / Double.MAX_VALUE / Double.MIN_VALUE

自动装箱 / 拆箱（MCQ 高频）：

Integer x = 42;       // 自动装箱：Integer x = Integer.valueOf(42);
int n = x;             // 自动拆箱：Integer 自动转为 int

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(10);          // 10 自动装箱为 Integer(10)
int first = nums.get(0); // 自动拆箱

关键考点（只考查以下内容）：
- ArrayList<int> 不允许（基本类型不能作为泛型实参），必须用 ArrayList<Integer>；
- 字符串 → 数字：Integer.parseInt("42") → 42、Double.parseDouble("3.14") → 3.14；
- 常量：Integer.MAX_VALUE / Integer.MIN_VALUE、Double.MAX_VALUE / Double.MIN_VALUE。

// MCQ 经典陷阱
double d = 10.0;
Double D = 20.0;
System.out.println(d + D);  // 输出 30.0（自动拆箱为 double + double）
String s = "" + d + D;       // 输出 "10.020.0"（拼接为字符串）

Topic 4.8 ArrayList 方法

完整 API 速查（考试必背）：

方法 签名 说明
构造器 new ArrayList<E>() 空列表
构造器 new ArrayList<E>(int initialCapacity) 指定初始容量（考试很少考）
add add(E e) 末尾追加，返回 boolean
add add(int index, E e) 在 index 处插入，原元素后移
get get(int index) 返回 index 处的元素
set set(int index, E e) 替换 index 处的元素，返回旧值
remove remove(int index) 删除并返回 index 处的元素
remove remove(Object o) 删除第一个等于 o 的元素，返回 boolean
size size() 当前元素个数
isEmpty isEmpty() 是否为空（size == 0）
contains contains(Object o) 是否包含 o（用 equals 比较）
indexOf indexOf(Object o) 第一个等于 o 的下标，没有返回 -1
clear clear() 清空所有元素

关键陷阱（MCQ 高频失分点）：

ArrayList<String> words = new ArrayList<String>();
words.add("jump");    // [jump]
words.add("right");   // [jump, right]
words.add("plan");    // [jump, right, plan]

words.add(2, "laugh");  // [jump, right, laugh, plan]  在 index=2 插入
words.add(3, "laugh");  // [jump, right, plan, laugh]  在 index=3 插入

words.set(2, "laugh");  // [jump, right, laugh]        set 是替换！
words.set(3, "laugh");  // IndexOutOfBoundsException    set(3) 不存在

words.remove(2);        // [jump, right]               remove(2) 删除并返回 "plan"
words.remove("right");  // [jump]                      remove(Object) 删除第一个匹配

「remove(int) 与 remove(Object) 的歧义」陷阱：

ArrayList<Integer> nums = new ArrayList<Integer>();
nums.add(10); nums.add(20); nums.add(30);   // [10, 20, 30]
nums.remove(20);  // ❌ 编译错！remove(int) 需要下标 0..size-1，但 20 不是下标
nums.remove(new Integer(20));  // ✅ 删除 20 这个元素（推荐写法：nums.remove(2);）

Topic 4.9 ArrayList 遍历

三种遍历模式（考试重点）：

ArrayList<String> words = new ArrayList<String>(Arrays.asList("a", "b", "c"));

// 1. 传统 for（需要下标时用）
for (int i = 0; i < words.size(); i++) {
    System.out.println(i + ": " + words.get(i));
}

// 2. 增强 for（只读访问时用，最简洁）
for (String w : words) {
    System.out.println(w);
}

// 3. 倒序遍历（删除元素时常用，避免下标错位）
for (int i = words.size() - 1; i >= 0; i--) {
    System.out.println(words.get(i));
}

// ❌ 错误：正向遍历 + remove，下标错位

for (int i = 0; i < nums.size(); i++) {
    if (nums.get(i) % 2 == 0) nums.remove(i);  // 删除 2 后，原 i=2 变成 4，被跳过！
}
// 结果：[1, 3, 5]  ← 错！应该是 [1, 3, 5] 但实际：[1, 3, 4, 5]  ← 4 没被删

// ✅ 正确方案 A：倒序遍历
for (int i = nums.size() - 1; i >= 0; i--) {
    if (nums.get(i) % 2 == 0) nums.remove(i);
}
// 结果：[1, 3, 5]  ✅

// ✅ 正确方案 B：正向遍历 + i--
for (int i = 0; i < nums.size(); i++) {
    if (nums.get(i) % 2 == 0) {
        nums.remove(i);
        i--;  // 重要：删完后回退一个下标
    }
}
// 结果：[1, 3, 5]  ✅

Topic 4.14 搜索算法

顺序搜索 vs 二分搜索（MCQ 必考）：

// 顺序搜索（Sequential Search）—— O(n)，适用于任何数组
public static int seqSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) return i;
    }
    return -1;
}

// 二分搜索（Binary Search）—— O(log n)，仅适用于**已排序**数组
public static int binSearch(int[] sorted, int target) {
    int lo = 0, hi = sorted.length - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (sorted[mid] == target) return mid;
        else if (sorted[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

MCQ 必会：
- 二分搜索的前提：数组必须已排序（升序）；
- 二分搜索每次比较后，搜索范围减半 → O(log n)；
- 顺序搜索遍历整个数组 → O(n)；
- n=1000 时，顺序搜索最多 1000 次比较；二分搜索最多约 10 次比较。

Topic 4.15 排序算法

三种排序的代码模板与复杂度（只考代码模板与 MCQ，不考 FRQ）：

// 1. 选择排序 Selection Sort —— 时间 O(n²)、空间 O(1)；每次从未排序部分找最小值，放到已排序末尾
public static void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        int tmp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = tmp;
    }
}

// 2. 插入排序 Insertion Sort —— 平均/最差 O(n²)、最优 O(n)，空间 O(1)；每次将当前元素插入到已排序部分的正确位置
public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

// 3. 归并排序 Merge Sort —— 分治法（divide and conquer），时间 O(n log n)、空间 O(n)
public static void mergeSort(int[] arr) {
    if (arr.length < 2) return;
    int mid = arr.length / 2;
    int[] left = Arrays.copyOfRange(arr, 0, mid);
    int[] right = Arrays.copyOfRange(arr, mid, arr.length);
    mergeSort(left);
    mergeSort(right);
    merge(arr, left, right);
}
private static void merge(int[] arr, int[] left, int[] right) {
    int i = 0, j = 0, k = 0;
    while (i < left.length && j < right.length) {
        if (left[i] <= right[j]) arr[k++] = left[i++];
        else arr[k++] = right[j++];
    }
    while (i < left.length) arr[k++] = left[i++];
    while (j < right.length) arr[k++] = right[j++];
}

Topic 4.16 递归基础

递归三要素（MCQ + FRQ 高频）：
1. Base case：终止条件，避免无限递归；
2. Recursive call：调用自身，参数必须向 base case 推进；
3. 进度：每次调用都必须让问题规模变小。

经典例子（必须能默写）：

// 阶乘
public static int factorial(int n) {
    if (n <= 1) return 1;          // base case
    return n * factorial(n - 1);   // recursive call，n 递减
}

// 数字各位之和
public static int digitSum(int n) {
    if (n < 10) return n;          // base case
    return n % 10 + digitSum(n / 10);  // 末位 + 递归处理剩余部分
}

// 数组求和（递归版）
public static int sumArray(int[] arr, int i) {
    if (i >= arr.length) return 0;        // base case
    return arr[i] + sumArray(arr, i + 1);  // 当前元素 + 递归处理剩余
}

MCQ 常见陷阱：

// ❌ 缺 base case：无限递归 → StackOverflowError
public static int bad(int n) {
    return bad(n - 1);  // 永远不停止
}

// ❌ base case 永远不进：n 永远不减
public static int worse(int n) {
    if (n == 0) return 1;
    return worse(n + 1);  // n 在增大，永远到不了 0
}

// ✅ 正确：n 每次减 1，最终到 base case
public static int good(int n) {
    if (n == 0) return 1;
    return n * good(n - 1);  // factorial
}

// (a) isNonZeroRow
public static boolean isNonZeroRow(int[][] array2D, int r) {
    for (int c = 0; c < array2D[r].length; c++) {
        if (array2D[r][c] == 0) return false;
    }
    return true;
}

// (b) resize
public static int[][] resize(int[][] array2D) {
    int numRows = numNonZeroRows(array2D);  // 必须用 helper
    int[][] result = new int[numRows][];
    int destRow = 0;
    for (int r = 0; r < array2D.length; r++) {
        if (isNonZeroRow(array2D, r)) {
            result[destRow] = array2D[r];  // 直接复制整行引用
            destRow++;
        }
    }
    return result;
}

public int longestHeatWave(double threshold) {
    int best = 0, cur = 0;
    for (double t : temperatures) {
        if (t > threshold) {
            cur++;
            if (cur > best) best = cur;
        } else {
            cur = 0;
        }
    }
    // 题目要求"two or more consecutive days"，所以小于 2 的不计入 heat wave
    return best >= 2 ? best : 0;
}

Part D · 评分要点

(a) 4 分：
- 必须倒序遍历或 i--（最常见的失分点！正向遍历下标错位）；
- 判断 t < lower || t > upper，满足则 remove(i)；
- 不要在遍历时 add / set（题目只要求 remove）。

(b) 4 分：
- 维护 best（最长）和 cur（当前连续段长度）两个计数器；
- 当前温度 > threshold：cur++，best = max(best, cur)；
- 否则 cur = 0（重要：必须归零，否则累计的是从开头到现在的所有 >threshold 的天数，不连续）；
- 题目要求"two or more"，单天不构成 heat wave，所以返回前判断 best >= 2（或预置 best = 0 但要求至少 2 天）。

FRQ-4（2024 International Q4 · GridPath）

Part A · Official English Wording (from College Board 2024 FRQ #4)

This question involves a path through a two-dimensional (2D) array of integers, where the path is based on the values of elements in the array. When an element of the 2D array is accessed, the first index is used to specify the row and the second index is used to specify the column. The following Location class represents a row and column position in the 2D array.

public class Location
{
    private int theRow;
    private int theCol;
    public Location(int r, int c) { theRow = r; theCol = c; }
    public int getRow() { return theRow; }
    public int getCol() { return theCol; }
}

The following GridPath class contains the 2D array and methods to use to determine a path through the array. You will write two methods of the GridPath class.

public class GridPath
{
    /** Initialized in the constructor with distinct values that never change */
    private int[][] grid;

    /** Returns the Location representing a neighbor of the grid element at row and col,
     *  as described in part (a) */
    public Location getNextLoc(int row, int col)
    { /* to be implemented in part (a) */ }

    /** Computes and returns the sum of all values on a path through grid, as described
     *  in part (b) */
    public int sumPath(int row, int col)
    { /* to be implemented in part (b) */ }
}

(a) Write the getNextLoc method, which returns a Location object that represents the smaller of two neighbors of the grid element at row and col, according to the following rules.

  • The two neighbors that are considered are the element below the given element and the element to the right of the given element, if they exist.
  • If both neighbors exist, the Location of the neighbor with the smaller value is returned. Two neighbors will always have different values.
  • If only one neighbor exists, the Location of the existing neighbor is returned.

(b) Write the sumPath method, which returns the sum of all values on a path in grid. The path begins with the element at row and col and is determined by successive calls to getNextLoc. The path ends when the element in the last row and the last column of grid is reached.

✍️ 建议先限时独立作答：可直接在下方输入框打草稿，或手写完成后对照参考解答。

Part C · 参考解法（Java）

// (a) getNextLoc —— 边界检查 + 比较下方和右方
public Location getNextLoc(int row, int col) {
    int rows = grid.length;
    int cols = grid[0].length;
    boolean below = (row + 1 < rows);
    boolean right = (col + 1 < cols);

    if (below && right) {
        if (grid[row + 1][col] < grid[row][col + 1]) {
            return new Location(row + 1, col);
        } else {
            return new Location(row, col + 1);
        }
    } else if (below) {
        return new Location(row + 1, col);
    } else if (right) {
        return new Location(row, col + 1);
    } else {
        return null;  // Precondition 保证不会到这里
    }
}

// (b) sumPath —— 累加 + 循环调用 getNextLoc
public int sumPath(int row, int col) {
    int sum = grid[row][col];
    int r = row, c = col;
    while (r < grid.length - 1 || c < grid[0].length - 1) {
        Location next = getNextLoc(r, c);
        r = next.getRow();
        c = next.getCol();
        sum += grid[r][c];
    }
    return sum;
}

Part D · 评分要点

(a) 4 分：
- 正确判断「下方邻居存在」「右方邻居存在」（row + 1 < rows / col + 1 < cols）；
- 两个都存在时比较 grid[row+1][col] 和 grid[row][col+1]，返回较小的；
- 只存在一个时直接返回那一个；
- 返回 new Location(...)。

(b) 4 分：
- 初始化 sum = grid[row][col]（起点也要加）；
- 循环条件：未到达右下角（r < rows - 1 || c < cols - 1）；
- 调用 getNextLoc(r, c)，更新 r 和 c；
- 累加 grid[r][c]；
- 返回 sum。

FRQ-5（2025 International Q4 · SumOrSameGame）

Part A · Official English Wording (from College Board 2025 FRQ #4)

This question involves reasoning about a number puzzle that is represented as a two-dimensional array of integers. Each element of the array initially contains a value between 1 and 9, inclusive. Solving the puzzle involves clearing pairs of array elements by setting them to 0. Two elements can be cleared if their values sum to 10 or if they have the same value. The puzzle is considered solved if all elements of the array are cleared.

You will write the constructor and one method of the SumOrSameGame class.

public class SumOrSameGame
{
    private int[][] puzzle;

    /** Creates a two-dimensional array and fills it with random integers,
     *  as described in part (a) */
    public SumOrSameGame(int numRows, int numCols)
    { /* to be implemented in part (a) */ }

    /** Identifies and clears an element of puzzle that can be paired with
     *  the element at the given row and column, as described in part (b) */
    public boolean clearPair(int row, int col)
    { /* to be implemented in part (b) */ }
}

A. Write the constructor for the SumOrSameGame class. The constructor initializes the instance variable puzzle to be a two-dimensional integer array with the number of rows and columns specified by the parameters numRows and numCols, respectively. Array elements are initialized with random integers between 1 and 9, inclusive, each with an equal chance of being assigned to each element of puzzle.

B. Write the clearPair method, which takes a valid row index and valid column index as its parameters. The array element specified by those indices, which has a value between 1 and 9, inclusive, is compared to other array elements in puzzle in an attempt to pair it with another array element that meets both of the following conditions.

  • The row index of the second element is greater than or equal to the parameter row.
  • The two elements have equal values or have values that sum to 10.

If such an array element is found, both array elements of the pair are cleared (set to 0) and the method returns true. If more than one such array element can be used, any one of those identified array elements can be used to complete the pair and can be cleared. If no such array element is found, no changes are made to puzzle and the method returns false.

For example, given a puzzle matrix, the call clearPair(0, 1) matches the value 7 at (0, 1) with the value 7 at (1, 0) and clears both.

✍️ 建议先限时独立作答：可直接在下方输入框打草稿，或手写完成后对照参考解答。

Part C · 参考解法（Java）

// A. 构造器
public SumOrSameGame(int numRows, int numCols) {
    puzzle = new int[numRows][numCols];
    for (int r = 0; r < numRows; r++) {
        for (int c = 0; c < numCols; c++) {
            puzzle[r][c] = (int) (Math.random() * 9) + 1;  // 1..9
        }
    }
}

// B. clearPair
public boolean clearPair(int row, int col) {
    int target = puzzle[row][col];
    for (int r = row; r < puzzle.length; r++) {           // 从 row 开始（含）
        for (int c = 0; c < puzzle[r].length; c++) {
            if (r == row && c <= col) continue;            // 跳过起点和起点之前的元素
            int val = puzzle[r][c];
            if (val == target || val + target == 10) {
                puzzle[row][col] = 0;
                puzzle[r][c] = 0;
                return true;
            }
        }
    }
    return false;
}

Part D · 评分要点

A. 4 分：
- 正确创建 puzzle = new int[numRows][numCols]；
- 嵌套 for 循环填充每个元素；
- Math.random() * 9 + 1 产生 1..9 的整数（注意强转为 int，否则是 double）；
- 起点从 (0, 0) 开始即可（题目说"each element"）。

B. 5 分：
- 从 (row, col) 开始（含 row，从 col+1 开始；或用 continue 跳过起点）；
- 嵌套遍历搜索匹配元素；
- 匹配条件：值相等或值之和为 10；
- 找到后两个元素都设为 0，返回 true；
- 找不到返回 false。

六、应试技巧清单

经验证的得分技巧（按效果排序）。

技巧 #1：阅读题目时先标记「数组类型 + 遍历方向」

每个题目先识别：
- 数据结构：int[] 数组 / ArrayList<E> / int[][] 2D 数组？
- 遍历方向：正向 / 倒序 / 嵌套？
- 关键 API：get(i) / set(i, e) / remove(i) / length / size？

技巧 #2：ArrayList 遍历删除时优先用倒序

for (int i = list.size() - 1; i >= 0; i--) {
    if (/* 需要删除 */) list.remove(i);
}

这是最不容易出错的写法，比 i-- 更直观。

技巧 #3：2D 数组遍历务必分清「行长度 vs 列长度」

for (int r = 0; r < grid.length; r++) {            // 行数 = grid.length
    for (int c = 0; c < grid[r].length; c++) {     // 列数 = grid[r].length（每行可不同）
        ...
    }
}

最常见的 bug：把列循环写成 c < grid.length（行数）→ 锯齿数组可能少遍历元素。

技巧 #4：二分搜索前必加注释「已排序」

// Precondition: arr is sorted in ascending order
public static int binSearch(int[] arr, int target) { ... }

未排序的数组用二分搜索结果未定义（不是返回 -1，而是返回某个垃圾下标）。

技巧 #5：递归题目先写 base case 再写 recursive call

public static int recurse(int n) {
    if (n == 0) return 1;          // base case 先写
    return n * recurse(n - 1);     // recursive call 后写
}

技巧 #6：写完方法后用题目给的示例验证

每个 FRQ 题目都会给一个或多个示例。写完代码后，用纸笔 trace 示例输入，确认每个返回值与示例一致。

技巧 #7：MCQ 时间分配

  • 单题不超过 60 秒；
  • 4 道 ArrayList 题（约 4 分钟）、4 道 2D Array 题（约 4 分钟）、3 道搜索排序题（约 3 分钟）、1 道递归题（约 1 分钟）；
  • 不会就猜（不倒扣分），但要避免在最后 5 分钟才猜。
